# VaniGuard website

Static VaniGuard concept website, ready to deploy on Vercel.

## Files
- `index.html`: page structure
- `style.css`: design and responsive layouts
- `script.js`: interactive scenario demos and controls
- `vercel.json`: static hosting configuration

## Deploy
Extract this folder and import it into Vercel, or run the Vercel CLI from this folder. No framework build command or output directory is required; Vercel serves `index.html` and its CSS/JS files directly.

The call-risk scenarios and guardian alert are simulated in the browser. This project does not capture live audio or send alerts.
