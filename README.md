# VaniGuard website

Static VaniGuard concept website, ready to deploy on Vercel.

## Deploy

1. Extract this folder.
2. Import the folder or its Git repository into Vercel, or run `vercel` from this folder.
3. No build command or output directory is required; Vercel serves `index.html` directly.

The call-risk scenarios and guardian alert are simulated in the browser. This project does not capture live audio or send alerts.
